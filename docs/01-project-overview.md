# Project Overview

## Executive Summary

This project documents the design, deployment and validation of a Windows Server 2025 Active Directory environment.

The lab was built in VMware Workstation Pro to simulate a small business infrastructure. The completed environment includes a domain controller, DNS, organisational units, users, groups, Group Policy, shared folders, NTFS permissions and a Windows 11 domain-joined client.

It also demonstrates common IT support procedures including password resets, account lockouts and access control.

## Project Purpose

The purpose of this project is to demonstrate practical Windows Server administration skills by deploying and documenting a functional Active Directory environment from installation through validation.

## Objectives

- Deploy Windows Server 2025 in VMware Workstation Pro.
- Configure Active Directory Domain Services (AD DS).
- Configure DNS for the `home.lab` domain.
- Create organisational units, users and security groups.
- Join a Windows 11 Enterprise client to the domain.
- Configure Group Policy Objects (GPOs).
- Configure departmental file shares and NTFS permissions.
- Validate the environment using realistic IT support scenarios.
